# IDEN-FICTION — Free Starter Website

A responsive, premium streetwear storefront built with plain HTML, CSS and JavaScript.

## Files
- index.html — website structure and content
- style.css — visual design and responsive layout
- script.js — demo shopping bag

## Free deployment
Upload the folder to a free static host such as GitHub Pages, Cloudflare Pages or Vercel.

## Before launch
1. Replace the placeholder product visuals with your real product photography.
2. Replace the placeholder size measurements with final tech-pack measurements.
3. Add your Instagram URL and contact details.
4. Connect a real checkout/payment provider.
5. Add privacy, shipping and return policies.

Brand direction used:
- IDEN-FICTION
- "WEAR YOUR IDENTITY"
- Premium oversized streetwear
- Black / off-white / charcoal / muted neutrals
- Identity words: NONCHALANT, WEIRD, SIDE QUESTER
